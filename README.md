# Gironte Pharma Logistics (GPLOG) - Website

Repositorio oficial del sitio web de **Gironte Pharma Logistics (GPLOG)** para pruebas de staging y despliegue continuo en **onrender.com**.

## 🚀 Estructura del Proyecto

- `index.html`: Estructura principal con soporte de idiomas [ES/EN], certificaciones (**IRAM-ISO 9001:2015**, **OEA**, **ANMAT**), servicios core y formulario de contacto.
- `css/style.css`: Hojas de estilo corporativas con paleta azul pharma y diseño responsive.
- `js/main.js`: Lógica de alternancia multilingüe (Español / Inglés).
